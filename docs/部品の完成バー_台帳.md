## 2. 面③ の借金 —— 34 部品

🟥 **状態面を持たない 34 部品には、「対象外」の理由も書かれていない。**
バー §4 は「**『対象外』には理由を書く**」と定めているが、**書く場所が無かった**（＝ 本ファイルが場所）。

**返し方は [部品1 D6=B] に揃える**——**一括では返さず、その部品を触るときに返す。**
理由: 🟥 **34 件を機械的に埋めると「埋めたこと自体が緑に見える」**（バー D5 が C を却下した理由と同じ）。
**状態面は「絵を足す」ことではなく「この部品にどの状態があるかを決める」ことなので、部品を触るときにしか正しく決められない。**

🟨 **例外として、いま理由が確定しているものだけ `—`（対象外）にした**——
`Spacer` / `Separator` / `Skeleton`（**ポインタにもフォーカスにも反応せず、データも文字も受けない**）。
