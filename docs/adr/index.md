# ADR 索引

> **横断決定の器。**一度決めると戻しにくいもの・外から見える構造や規約に影響するものを、MADR 準拠で積む。
> 形は PoC の `docs/adr/` に合わせている（`stage` → `step`）。テンプレ: [_template.md](_template.md) ／ 語彙の正本: `.claude/trace.config.mjs`

## DR との使い分け

| | 入れるもの |
|---|---|
| **DR** | 作業中に定まった判断。**1 決定 or 1 発見**。ほとんどはここで終わる |
| **ADR** | **アーキ級。**戻しにくい／外から見える構造・規約に影響するもの |

**判定と起案を分ける。**DR を書く時点で「昇格候補」とマークだけし、**起案は根拠が揃った時機に行う**（DR 確定時点では実測が足りないことが多い）。

## status の意味（MADR）

`proposed`（起案）→ `accepted`（採用）｜ `rejected`（不採用）／ `deprecated`（役目を終えた）｜ `superseded`（後続 ADR に置き換わった）
