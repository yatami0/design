# OBS-0022: 他の機械ゲートにも「保留」の口があるか

> 凡例：🟦 確定／根拠あり ・ 🟨 暫定／裁量 ・ 🟥 未確認・要本人確認

## 0. 一行サマリ【起票時必須】

## 1. きっかけ（何を見て・何に引っかかったか）【起票時必須】

## 2. 経緯と今の理解【起票時必須・「わからない」でもよい】

**候補**（🟥 **どれも数えていない**）:

| ゲート | 「保留」に相当しうるもの | 既に知っていること |
| --- | --- | --- |
| `tsc` | `skipLibCheck` の下、`any` / `as` による打ち切り | 🟥 **未決 #29**: 出荷している `.d.ts` 26 件が型検査を通らない（**知っているが数えていない**） |
| `eslint` | `warning`（落とさない）／ `eslint-disable` コメント／ 規則が当たらない構文 | 🟦 warning は **1 件**（ベースライン表にある）。🟥 **disable コメントは数えていない** |
| `cspell` | **辞書に足した語** | ★★ 🟥 **これは「分からない」を「分かる」に書き換えた記録そのもの**（346 → 349 → 350 と増えている） |
| `prettier` | `.prettierignore` の中身 | 🟥 **`src/components/ui/**` を丸ごと除外している**（素材層＝ 整形ゲートの外） |
| `vite build` | 🟥 **型エラーを赤い字で出しながら `exit 0`** | 🟦 [DR-0082](../DR/DR-0082-vite-build-prints-type-errors-but-exits-zero.md)。**保留ですらなく黙殺** |
| `build-storybook` | 🟥 **story が実行時に落ちても `exit 0`** | 🟦 [DR-0048](../DR/DR-0048-build-storybook-does-not-render.md) |
| `test-storybook` | `skip` / `todo` タグ ／ 🟥 **`play` を持たない story**（＝ 主張が 0 本） | 🟥 **`play` を持たない story の数を、一度も数えていない** |

★★ **いちばん筋が良さそうなのは 2 つ**——
🟥 **`cspell` の辞書**（**足した語＝ 判定を人が覆した回数**）と、
🟥 **`play` を持たない story の数**（**バーは回っているが、その story は何も主張していない**）。
