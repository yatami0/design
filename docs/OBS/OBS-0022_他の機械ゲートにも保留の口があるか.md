### 次に機械化すべきはどれか（D6=A の結論）

🟦 **`test-storybook` の被覆**（→ **この回で機械化した**: `tools/coverage-scan.mjs`）と
🟦 **`tools/*.mjs` の型と赤テスト**（→ **この回で機械化した**: `pnpm typecheck:tools` / `pnpm self-check`）。

🟨 **残りは機械化しない。**理由——
- **`format:check` の 219 件と `spell` の 90 語は、理由が既に文書に書かれており、増分は `git diff` で見える。**
- 🟥 **`build` / `build-storybook` の exit 0 は「保留」ではなく設計上の黙殺**で、**数える対象が無い**（塞ぐなら別の手段が要る）。
- 🟥 **`tsc` の 2 つの借金（6 件 / 7 件）は残高であって保留ではない**——**返す判断は [DR-0014](../DR/DR-0014-exact-optional-property-types-incompatible.md) と未決 #29 が持つ。**
