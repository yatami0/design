# OBS-0018: リンクが本文と見分けられない

> 凡例：🟦 確定／根拠あり ・ 🟨 暫定／裁量 ・ 🟥 未確認・要本人確認

## 0. 一行サマリ【起票時必須】

🟦 **`Link tone="primary"` の色は本文色と 1 ビットも違わない**（どちらも `rgb(0,0,0)`）。
下線は `hover` / `focus-visible` のときだけ付くので、**静止状態のリンクは本文と区別が付かない。**

## 1. きっかけ（何を見て・何に引っかかったか）【起票時必須】

部品1 B1-06b で `Link` に**面④（語彙の効果）**の `play` を書いたとき、
「Preflight の `color: inherit` に戻っていないこと」を確かめるつもりで
**「リンクの色は親の色と違うはず」**と書いたら、**赤になった。**

```
AssertionError: expected 'rgb(0, 0, 0)' not to be 'rgb(0, 0, 0)'
```

## 2. 経緯と今の理解【起票時必須】

🟦 **`tone` は効いている。**`getComputedStyle(a).color` は `--primary` の実効値と一致する
（面④ の判定は通っている）。**問題は「効いた結果」のほう。**

🟦 **値はどちらも黒で、しかも意図的**——`src/styles/tmp-admin.css`:

| custom property | 値 | 由来 |
| --- | --- | --- |
| `--foreground` | `rgba(0, 0, 0, 1)` | apple `--color-label` |
| `--primary` | `rgba(0, 0, 0, 1)` | 🟥 **`accent` を入れない**（tmp-admin V2「accent は塗りに使わない」・[DR-0005](../DR/DR-0005-token-ownership-and-two-stage.md)） |

🟦 `src/components/Navigation/Link.tsx` が当てるのは `TONE[tone]` ＋ `hover:underline focus-visible:underline` だけ。
**静止状態の下線は無い。**

★ **つまり「リンクだと分かる手がかり」が 0 個**——色は本文と同じ、下線は触らないと出ない。
🟥 **これは WCAG 1.4.1（色だけで情報を伝えない）の領域**だが、
🟦 **axe では検出できない**——`color-contrast` が見るのは**前景と背景**の比で、
リンクの色は本文と同じなので**本文が通れば通る**。**リンクと本文の対比は誰も測っていない。**

## 3. 知識の結びつき ★主目的

- 既に持っていた知識・経験：[DR-0090](../DR/DR-0090-token-classes-were-silently-dropped-by-tailwind-merge.md)（**型は受けるが作用しない**）
- 今回新しく得た・繋がった知識：**作用はしているのに、作用した結果が役に立たない**という 3 つ目の壊れ方がある
- 結びついて生まれた気づき（1 行の一般則）：
  🟨 **「語が効いているか」と「効いた結果が使えるか」は別の検査で、後者は機械に載っていない**
  （完成バーの言い方では **面④（機械）と面⑦（人）の境目**）

## 4. 結論と保留

- **今の結論**：🟨 **仕様どおりであり、かつ使えない。**tmp-admin の V2 原則（accent を塗りに使わない）は
  **面の設計**の話で、**リンクという「文中の要素」を想定していない**可能性がある
- **保留・未確認**：🟥 **どう直すかは決めていない。**候補は 3 つ——
  ① 静止状態にも下線を付ける（`underline` を既定に） ／
  ② `Link` 用の色語彙を別に立てる（`--color-link`） ／
  ③ tmp-admin の原則ごと見直す
  🟥 **①〜③ はどれも「見た目の管轄権はコア」（[DR-0070](../DR/DR-0070-product-layer-boundary-rule.md)）に触るので、この回では決めない**
- **この結論が変わる条件**：**5 画面のどれかで本文中リンクが実際に使われたとき**
  （現状 `Link` の実利用は一覧の件名など「単独で置かれる」形だけで、**文中リンクはまだ 1 件も無い**）

## 5. 却下した代替案【任意】

| 案 | 内容 | 却下理由 |
|---|---|---|
| `play` に「親の色と違う」を残す | 面④ で落とす | 🟥 **仕様どおりの状態を赤にする**＝ 直せない赤が常時点灯し、[OBS-0017](OBS-0017_意味色とfillの対比が全滅している.md) と同じ理由でベースライン運用が壊れる |
| この回で下線を既定にする | 1 行で直る | 🟥 **変数が増える。**部品1 B1-06 はバーを通す回であって見た目を決める回ではない。**5 画面の見た目が動く** |
