# OBS-0010: フォント修正で手5 の目視判定をやり直すか

> 凡例：🟦 確定／根拠あり ・ 🟨 暫定／裁量 ・ 🟥 未確認・要本人確認

## 0. 一行サマリ【起票時必須】

手6 で **Storybook が本体と違うフォント（セリフ体）で描いていた**ことが判明し修正したので、
**そのセリフ体の上で行われた手5 の目視レビューを、どこまでやり直すか**が決まっていない。

## 1. きっかけ（何を見て・何に引っかかったか）【起票時必須】

手6 の compare ループで最初の検体（`Button`）を見たとき、**storybook 側・preview 側とも書体がセリフ**だった。
追うと `--font-sans` が `@theme inline` で自己参照しており、埋めていたのは
`layout.tsx` の `next/font`（Geist）だけ。**Storybook は `layout.tsx` を実行しない**ので
変数が未定義になり、ブラウザ既定に落ちていた（[DR-0058](../DR/DR-0058-app-only-font-never-reached-the-design-system.md)）。

→ **手5 の目視レビューは、すべてこのセリフ体の上で行われていた。**

## 2. 経緯と今の理解【起票時必須・「わからない」でもよい】

**問い**: 書体が変われば、手5 の目視判定のうちどれが揺れるか。

観点ごとに、書体依存の度合いが違う。

| 観点 | 手5 の判定 | 書体依存か |
| --- | --- | --- |
| **D タイポ** | 🟦「weight 600 はうるさくない」→ **600 のまま**（ユーザー確認済み） | 🟥 **直撃する。**ウェイトの見え方は書体で変わる |
| **A 状態面** | 🟨「色は合っているのに濃さが違う」 | 🟦 ほぼ無関係（面の色） |
| **B 角丸** | 🟨「7.2/8 は分からない」→ [DR-0052](../DR/DR-0052-unreachable-spots-are-avoided-by-not-using-them.md) | 🟦 無関係 |
| **C 影** | 🟥「sm と md がほぼ同じに見える」 | 🟦 無関係 |
| **E·F オーバーレイ** | 🟦「背景はぼやけていない」 | 🟦 無関係 |
| **I 層の比較** | 🟦 ペア 2・3 とも確認済み | 🟨 文字が入るので多少は影響しうる |

🟨 **現在の理解: 揺れるのは実質 D だけ。**ただし D は
**「600 のまま」というユーザー判断の根拠**になっているので、放置すると
**根拠が消えた決定が 1 件残る。**

**何がわかれば解けそうか**: `pnpm storybook` で `★ Review/D タイポ` を開き直して
**サンセリフの上で同じ判断になるか**を見るだけ。所要は数分。

- 今回新しく得た・繋がった知識：🟥 要確認
- 結びついて生まれた気づき：🟥 要確認

## 4. 結論と保留

- **今の結論**：🟨 **やり直すのは観点 D だけでよい**（他 5 観点は書体に依存しない）
- **保留・未確認**：🟥 **やり直すかどうか自体が未決。**手6 のうちにやるか、手7 以降へ送るか
- **この結論が変わる条件**：D を見直して**判断が変わった**ら、[DR-0026](../DR/DR-0026-two-css-pipelines-differ.md)
  （判定は Storybook 側に固定する）の扱いも見直す必要が出る

## 5. 却下した代替案【任意】

| 案 | 内容 | 却下理由 |
| --- | --- | --- |
| 全観点をやり直す | A〜I をもう一度通す | 🟥 **6 観点中 5 つは書体に依存しない。**費用対効果が悪い |
| 何もしない | 記録だけ残す | 🟨 却下ではなく**選択肢として残す**。ただし「根拠が消えた決定」が 1 件残ることは明記が要る |

## 6. DR への導線【棚卸し時必須】

- **DR 化**：🟨 **判断保留。**見直して判断が変わったら decision、変わらなければ finding として 1 行で足りる
- **関連する既存 DR**：[DR-0058](../DR/DR-0058-app-only-font-never-reached-the-design-system.md)（原因）／
  [DR-0026](../DR/DR-0026-two-css-pipelines-differ.md)（判定を Storybook に固定した決定）／
  [DR-0053](../DR/DR-0053-viewpoints-must-be-answerable-by-eye.md)（観点は誰が答えられるかで分ける）
- **PoC へ戻す候補か**：🟨 **候補。**「目視レビューの基準器が本体と一致しているかを、レビュー前に確かめる」は
  PoC の ADR-0009（ビジュアル回帰）にそのまま効く
