## 2. 経緯と今の理解【起票時必須・「わからない」でもよい】

### 分かっていること（実測ベース）

| 事実 | 出典 |
| --- | --- |
| shadcn は状態面を「**意味色 + 不透明度**」で作る。`destructive/10` `/20` `/30` の **3 段** | [DR-0045](../DR/DR-0045-opacity-modifiers-were-invisible-to-lint.md) |
| tmp-admin V4 は「**専用の tint 色**」で作る。`--fill-danger: rgba(255,59,48,0.16)` の **1 段** | トークンマッピング 2.4 |
| `bg-destructive/10` は `color-mix(in oklab, var(--destructive) 10%, transparent)` を出す。**色は追従・不透明度は焼き込み** | H5-03 |
| 素材層に **17 種 60 箇所**ある | [DR-0045](../DR/DR-0045-opacity-modifiers-were-invisible-to-lint.md) |
| 実測: `bg-destructive/10` → `oklab(0.654 0.204 0.111 / 0.1)` ／ StatusPill → `rgba(255,59,48,0.16)` | H5-07 |

### 🟥 学習したいこと（まだ理解できていない）

1. **「不透明度で作る面」と「専用の色で作る面」は何が違うのか。**
   結果の見た目が同じでも、設計上の意味は違うのか
2. **なぜ shadcn は 3 段、tmp-admin は 1 段なのか。**段数の違いは何を表しているのか
3. **`color-mix(in oklab, …)` の `oklab` は何をしているのか。**
   sRGB で混ぜるのと何が違い、なぜ見た目に効くのか
4. **透過（alpha）と「同じ見た目の不透過色」は等価か。**
   `rgba(255,59,48,0.16)` を白の上に置いたのと、それを焼き込んだ不透過色は同じか。
   **重なったとき**に違いが出るはずだが、その理解が曖昧
5. **アクセシビリティ上のコントラスト計算は、透過があるとどう変わるのか**

### 何がわかれば解けそうか

- 上の 5 点を、**実物で並べて確かめる**（`★ Review/A 状態面` を拡張すれば実験台になる）
- tmp-admin / apple の哲学が **なぜ tint を専用色にしたか**を一次情報で辿る
