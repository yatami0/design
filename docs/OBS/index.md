# OBS 索引（観点台帳）

> **個人の疑問・気づきを貯めて、定期的に見直して結びつける台帳。** DR（決定・発見）の上流。
> テンプレ: [_template.md](_template.md) ／ 語彙の正本: `.claude/trace.config.mjs` ／ 起票・棚卸しは `/obs` skill
> 形は PoC の `docs/OBS/` に合わせている（`stage` → `step`、OQ は本 repo に無いので DR 一本）。

## DR との使い分け

| | 入れるもの |
|---|---|
| **OBS** | **まだ決まっていないもの。** わからないまま進めた疑問・結びついた気づき |
| **DR** | **定まったもの。** 決めたこと（`decision`）／実測で分かったこと（`finding`） |

**決まっていないものを DR に積まない。**台帳の意味が壊れる。逆に、OBS が結びついて判断が定まったら DR へ昇格させる。

## status の意味

`open`（未消化。**棚卸しの対象**）→ `connected`（知識が結びつき §3 記入済み）→ `promoted`（DR 昇格済）| `closed`（解消・見送り）
