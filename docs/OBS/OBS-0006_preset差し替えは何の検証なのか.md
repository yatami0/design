# OBS-0006: preset ごと差し替える軸は何を検証する手なのか（未決 #6）

> 凡例：🟦 確定／根拠あり ・ 🟨 暫定／裁量 ・ 🟥 未確認・要本人確認

## 0. 一行サマリ【起票時必須】

「`preset` ごと差し替える軸」を手5 に含めるかを未決 #6 として持ち回ってきたが、
**そもそもこの軸が何を確かめる手なのかが定義されていない。**手5 からは外したが、**外した先が決まっていない。**

## 1. きっかけ（何を見て・何に引っかかったか）【起票時必須】

未決 #6 は [DR-0016](../DR/DR-0016-shadcn-deps-are-caret-ranges.md) を起点に「手5」と書かれたまま

含めた場合に何が観測できるのかが、はっきりしていない。

## 2. 経緯と今の理解【起票時必須・「わからない」でもよい】

### 分かっていること

- 🟦 現在の preset は `nova`（`base=radix`・CLI `4.15.0` 固定＝[DR-0006](../DR/DR-0006-shadcn-base-radix-preset-nova.md)）
- 🟦 **トークンでは解けない衝突が実在する。**[トークンマッピング 表3](../トークンマッピング.md) の #1（塗り CTA という「形」）・
  #3（blur）・#5（weight 500）・#7（`h-8` の高さ）は、**値ではなく `variant` 定義の問題**
- 🟦 このうち #3・#5 は [DR-0041](../DR/DR-0041-tailwind-v4-seams-differ-per-utility.md) で
  **トークン側から解けることが分かった**（`--blur-xs` / `--font-weight-medium`）。
  → **「preset を変えないと解けない」と思われていたものが減っている**

### 問い

**preset 差し替えは「トークン差し替えの延長」なのか、「別の検証軸」なのか。**

- もし延長なら手5 に含めるのが自然だが、**Q1〜Q3 は全部「トークンの追従」を測る問い**なので、
  preset を同時に動かすと**何が原因で変わったのか切り分けられなくなる**
- もし別軸なら、**何を確かめる手なのかを定義してから、どの手に置くかを決める**必要がある

### 仮説（🟥 本人未確認）

preset 差し替えが答えるのは「**トークンで解けない衝突を、部品の選び直しで解けるか**」という問いではないか。
だとすれば置き場は手5 ではなく、**手7（Claude Design が組んだものを使うか作り直すか）と同じ「作り直しの是非」の系列**にある。

🟥 **これは Claude の整理であって本人の見立てではない。**

### 何がわかれば解けそうか

- 手5 の結果。**トークンで解けない衝突が最終的に何件残るか**が分かれば、
  preset を動かす動機の大きさが測れる（残りが 1〜2 件なら、preset ごと替える価値は薄い）

## 4. 結論と保留

- **今の結論**：🟨 **手5 には含めない**（ユーザー判断 2026-07-26・推奨どおり）。
  手5 の Q1〜Q3 はすべて「トークンの追従」を測る問いなので、
  preset を同時に動かすと**何が原因で変わったのかを切り分けられなくなる**
- **保留・未確認**：🟥 **どの手に置くかは決まっていない。**「手7 以降」としか言えていない。
  🟥 **この軸が何を検証する手なのかの定義も無い**（§2 の仮説どまり）
- **この結論が変わる条件**：手5 でトークンで解けない衝突が多く残った場合、
  **preset を動かす動機がはっきりする**ので、独立した手として定義できるようになる
