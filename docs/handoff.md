
> `git stash -u` して HEAD 単体で回す**対照実験**で、**私の変更前から赤 2 件**であることを確認済み。
> → 辞書に `aisy` / `wcag` / `dtcg` / `shadeed` / `dodds` / `martinfowler` を追加し、**緑に戻した**（手2b で `largetitle` 等を足したのと同じ扱い）。

```bash

```
