# DR-0063: 禁止だけでは破られ、代替語彙を与えると守られた

## 背景

手7 は同じ依頼文で 3 周まわした。**1 周ごとに変数を 1 つだけ動かした。**

| 周 | 動かした変数 | 依頼文 | 語彙表 |
| --- | --- | --- | --- |
| 1 | — | 明示なし | 幅の族なし |
| 2 | **部品 14 → 30**（素材層 16 を追加） | **同一** | **同一** |
| 3 | **語彙に `w-field-*` を追加**（[DR-0061](DR-0061-field-width-vocabulary.md)） | **同一** | 幅の族を追加 |

## 発見

### ★ 語彙を足した箇所は、次の周で語彙どおりに書かれた

| 観測 | 1 周目（14 部品） | 2 周目（30 部品） | 3 周目（30 部品 ＋ 語彙） |
| --- | --- | --- | --- |
| 使った部品の**種類** | 10 | 17 | 🟦 **18**（＋`Container`） |
| 🟥 **数値の段**（`p-4` 等） | 0 | 🟥 **`w-48` × 2** | 🟦 **0** |
| **`w-field-*`** | — | — | 🟦 **`w-field-md` × 2** |
| 宣言語彙**外**の実在クラス | `bg-card` `border` `rounded-md` `font-emphasis` `tabular-nums`（**5**） | `font-emphasis` `tabular-nums`（**2**） | 🟦 **`tabular-nums`（1）** |
| 宣言語彙**どおり**のクラス | `text-label` | `text-label` `text-emphasis` | 🟦 **`text-label` `text-emphasis` `text-table`** |
| 素の `<span>`（**コード上の出現箇所**） | 8 | 5 | 🟦 **2** |
| パレット色 / 生 hex / 生 px / インライン `style` | 0 | 0 | 🟦 **0** |

**3 周を通して逸脱が減り続けた。減らし方は 2 種類だけ。**

1. **部品を足す**（2 周目）→ `Card` が来て `Box` + `bg-card rounded-md border` の手組みが消えた
2. **語彙を足す**（3 周目）→ `w-field-md` が来て `w-48` が消えた

🟥 **どちらも「禁止を強めた」わけではない。**conventions header の禁止文
（`p-4` / `w-99` / パレット色）は 3 周とも**1 文字も変えていない。**

### 🟨 副次的に、宣言語彙の**使用**も増えた

3 周目で `text-table` が初めて使われた（表セル）。**幅の語彙を足しただけなのに、
タイポの語彙も使われ始めている。**🟥 因果は特定できない（同時に部品も増えている）。

### 🟨 数え方の限界を 1 つ明示する

素の `<span>` の「8 → 5 → 2」は**コード上の出現箇所**の数。
3 周目は agent が `const cell = (v, cls) => React.createElement('span', …)` と
**ヘルパーに畳んだ**ため 1 箇所に見えるが、**実行時には 6 列ぶんのノードが出る。**
→ **「span が減った」は書き方の変化であって、DOM の変化ではない。**

### 🟥 3 周とも消えなかったもの

| 残ったもの | 出どころ | 3 周とも |
| --- | --- | --- |
| `tabular-nums` | `DataGrid.columns[].cell` の任意 JSX（[DR-0060](DR-0060-vocabulary-leaks-from-four-surfaces.md) の面 ③） | 🟥 出続けた |
| `<style>` への生 CSS | helmet（面 ④） | 🟥 **2 周目・3 周目とも `a { color: var(--primary) }` 系が出た**（2 例目） |

**面 ③ と ④ は語彙では塞がらない。**[DR-0060](DR-0060-vocabulary-leaks-from-four-surfaces.md) の予想どおり。

## 根拠（実測）

2026-08-02。生成物 3 本を同一の grep 群で数えた。

```
artifacts/h7/RedmineIssueList.dc.html      1 周目（14 部品）
artifacts/h7/redmine-issue-list.dc.html    2 周目（30 部品）
artifacts/h7/RedmineIssueList-r3.dc.html   3 周目（30 部品 ＋ w-field-*）
```

計測器は手7 H7-06 で赤テスト済みのもの（`<div class="p-4 text-gray-600"><button style="color:#ff0000">` を
入れて 4 パターンとも発火することを確認済み）。

## 影響

**観測から直接言えること**

1. ★ **「禁止だけして代替を与えていない語彙は破られる」の対偶が実測で出た**——
   **代替を与えたら守られた。**しかも禁止文は一切強めていない。
2. ★ **手7 Q3 の答えが確定した。**1 周目 0 → 2 周目 2 件 → **3 周目 0 件**。
   🟥 **ただし「宣言語彙の外」はゼロにならない**（`tabular-nums` が残る）。
3. 🟦 **[DR-0061](DR-0061-field-width-vocabulary.md) の「まだ言えないこと」が言えるようになった。**
   「部品を足したら使う」（2 周目）と「語彙を足したら使う」（3 周目）は**別々に確認された。**
4. 🟥 **面 ③（`cell` レンダラ）と面 ④（生 CSS）は 3 周とも塞がらなかった。**
   面 ④ は**2 例目**なので、[2 回ルール](../../CLAUDE.md)の観点では対処を検討してよい段階。

**🟥 推論（未検証）**

- **`tabular-nums` を語彙表に足せば面 ③ も守られる**かもしれないが、
  `cell` は**任意 JSX を受ける穴**なので、語彙を足しても次は別の語が出る可能性がある。
  🟥 **語彙の追加で解けるのは「用途が有限で名前を付けられるもの」だけ**という仮説。未検証。
- 3 周とも同じ依頼文だが、**agent の出力は毎回違う**（ダミーデータも構造も）。
  **決定的ではない**ので、1 回の観測を一般則にしない。**3 周そろって初めて傾向として読んだ。**
