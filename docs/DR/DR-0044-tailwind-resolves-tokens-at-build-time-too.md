# DR-0044: 「var() を出さない」と「`@theme` が効かない」は別物（DR-0041 の推論を訂正）

## 背景

[DR-0041](DR-0041-tailwind-v4-seams-differ-per-utility.md) は生成 CSS を読み、
`shadow-md` が `var(--shadow-md)` ではなく**リテラルを出力する**ことを観測した。
そこから **「影は追従しない」「`@theme` に `--shadow-md` と書いてもビルドは緑で何も変わらない」**と推論し、
[DR-0043](DR-0043-recount-of-fifteen-unchanged-spots.md) は影 7 箇所を
「レイヤ外上書きでしか解けない（乙）」に分類した。

手5 の **H5-02（赤テスト）でこの推論を確かめたところ、外れた。**

## 発見

**`@theme` に `--shadow-md` を定義すると、`.shadow-md` は変わる。**
出力に `var()` が無いのは「参照していない」からではなく、**ビルド時に解決して焼き込んでいる**から。

### 解決のタイミングで 3 種類に割れる

| 種別                       | 例                                              | 生成 CSS                                    | `@theme` で変わるか | 実行時に切り替わるか |
| -------------------------- | ----------------------------------------------- | ------------------------------------------- | ------------------- | -------------------- |
| **① 実行時参照**           | `font-medium` / `backdrop-blur-xs` / `rounded-lg` / `text-sm` | `var(--font-weight-medium)` など            | 🟦 **変わる**       | 🟦 **切り替わる**    |
| **② ビルド時解決**         | `shadow-xs/sm/md/lg/xl`                         | 値を焼き込む（`:root` に変数は出ない）      | 🟦 **変わる**       | 🟥 変わらない        |
| **③ 解決しない（任意値）** | `rounded-[4px]` / `ring-[3px]` / `min-w-[96px]` | 値を焼き込む                                | 🟥 **変わらない**   | 🟥 変わらない        |

🟥 **DR-0041 は ② と ③ を混同していた。**どちらも「生成 CSS にリテラルが出る」という点では同じに見えるが、
**② は `@theme` の定義を読んでいる。**

### 手5 にとっての意味

手5 の問いは「**トークンを差し替えたとき部品を触らずに見た目が変わるか**」であって、
「実行時に切り替わるか」ではない。**差し替えはビルドを伴う**ので、**② は追従する側**に入る。

（実行時の切り替え——`.dark` やライブなテーマトグル——を要求する場面では ② は使えない。
本 repo では dark は対象外＝[DR-0020](DR-0020-dark-mode-out-of-scope.md) なので、この区別は手5 の判定に影響しない。）

## 根拠（実測）

2026-07-26。手5 の H5-02（赤テスト）。`git status --porcelain` が空の状態から開始し、終了後も空であることを確認済み。

**プローブ**: `src/app/tokens.css` の末尾に `@theme { --shadow-md: 0 0 0 4px red; --font-weight-medium: 900; }` を追記し `pnpm build-storybook`（exit 0）。

| 観測                     | ベースライン                                                | プローブ後                        |
| ------------------------ | ----------------------------------------------------------- | --------------------------------- |
| `.shadow-md`             | `--tw-shadow:0 4px 6px -1px var(--tw-shadow-color,#0000001a), …` | `--tw-shadow:0 0 0 4px var(--tw-shadow-color,red)` 🟦 **変わった** |
| `.shadow-lg`（**対照**） | `0 10px 15px -3px …`                                         | **同一** 🟦 段ごとに独立している   |
| `:root` の `--shadow-md` | 出ない                                                       | **出ない** 🟥 実行時の継ぎ目は無い |
| `:root` の `--font-weight-medium` | `500`                                              | `900` 🟦                           |
| `.font-medium`           | `font-weight:var(--font-weight-medium)`                      | **同一**（参照の形は保たれる）    |

撤去は `git checkout src/app/tokens.css`（`rm -rf` は使っていない＝手3 の事故を踏まえて）。

### 同時に確かめた 2 件（H5-02 の (3)）

- 🟥 **`@theme { --spacing: initial }` で `p-4` / `gap-2` / `px-3` が生成されなくなり、CSS が 70,700 → 60,942 bytes（−9,758）になったが、`pnpm build-storybook` は exit 0。**
  → [OBS-0003](../OBS/OBS-0003_対象0件で緑が5回出た.md)「対象 0 件で緑」の **6 例目**。
  **手5 の判定をビルドの成否で行ってはならないことが、手5 自身の中で再確認された。**

## 影響

- 🟥 **[DR-0041](DR-0041-tailwind-v4-seams-differ-per-utility.md) の「影響」節の推論を訂正する**（観測した CSS 出力の表は正しいので維持する。
  [DR-0030](DR-0030-touch-target-provenance-corrected.md) が [DR-0023](DR-0023-real-conflict-is-touch-target.md) の発見 2 だけを訂正したのと同じ扱い）。
- 🟦 **[DR-0043](DR-0043-recount-of-fifteen-unchanged-spots.md) の内訳が動く。影 7 箇所が 乙 → 甲 へ移る。**

  | 判定                          | DR-0043 | **訂正後**            |
  | ----------------------------- | ------- | --------------------- |
  | 🟦 甲 ① 層だけで動く          | 2 件（17 箇所） | **3 件（24 箇所）** |
  | 🟨 乙 素材層を触らず接続すれば動く | 6 件 | **5 件**            |
  | 🟥 丙 本当に変わらない        | **1 件** | **1 件**（変わらず） |
  | ⬜ 対象外                     | 6 件    | 6 件                  |

  🟦 **「本当に変わらないのは 1 件」という結論は変わらない。**動いたのは甲と乙の境界。
- 🟦 **手5 §2 の D1 の射程が縮む。**「上書きでしか解けない」のは**スクリム 2 箇所だけ**になった
  （`bg-black/10` は不透明度 10% がクラス名側に焼き込まれており、tmp-admin の `rgba(0,0,0,0.40)` へは向けられない）。
  → 2 周目「無理」の対象が 9 箇所 → **2 箇所**。**D1=D（2 段測る）の判断自体は維持**（測る対象が小さくなっただけ）。
- 🟥 **教訓: 生成物を読んだだけで「効かない」と結論しない。**
  [DR-0006](DR-0006-shadcn-base-radix-preset-nova.md)（公式 docs が古い）・[DR-0022](DR-0022-shadcn-has-component-tokens.md)（3 層は実在した）・
  [DR-0025](DR-0025-storybook-init-is-not-selectable.md)（生成物は全文読む）に続き、
  **「一次情報を実測で置き換える」の 6 例目。今回は自分が 1 手前に書いた DR が対象だった。**
- 🟦 **H5-02 を H5-03 より前に置いた判断が効いた。**この誤りは
  **1 周目の差し替えを全部やってから「影が変わってしまった」形で発覚するはず**だった。
  赤テストを先に置いたので、**表1 を流し込む前に分類を直せた。**
