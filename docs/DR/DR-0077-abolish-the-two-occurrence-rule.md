# DR-0077: 2 回ルールを廃止する

## 背景

本 repo は CLAUDE.md に「**仕組みは必要性が 2 回証明されるまで作らない**」を置き、
[DR-0070](DR-0070-product-layer-boundary-rule.md) の判定手順は**その第 1 段**に
「同じ場所から逸脱が 2 回以上出たか — No なら作らない」を据えていた。

**2026-08-07、ユーザー判断で廃止する**（「2 回ルールいらないから消してくれ、これのせいでおかしくなっている」）。

## 決定

1. **2 回ルールを廃止する。**「同じ需要が 2 回証明されるまで作らない」を判断の条件にしない。
2. **[DR-0070](DR-0070-product-layer-boundary-rule.md) の判定手順を 3 段 → 2 段にする**（規則①を落とす）。**残る 2 段はそのまま生きる**:
   - **① その選択はトークン語彙の有限集合で表せるか** — Yes なら製品層で作る（union props で型に閉じる）
   - **② No（自由合成が本質）なら誰かの責務に割り当てられるか** — Yes ならその部品・層に引き取らせる ／ No なら ReactNode で受けて「残す」と明記し、監視方法を決める
   - → **DR-0070 は superseded。本書が置き換える。**境界の原理（見た目の管轄権）は変わらない
3. **回数は判断の条件ではなく、記録する観測量として残す。**「何周で何回出たか」は実行記録・設計文書に書き続ける
   （**数えるのをやめるわけではない**）。変わるのは「**回数が閾値に届くまで動けない**」という縛りだけ。
4. **「まだ作らない」と決めるときは、回数ではなく理由を書く。**
   例: 「語彙で表せないから」「責務の持ち主が決まっていないから」「見た目が変わるから」。
   🟥 **「1 回目だから」は今後は理由にならない。**

## 影響

**観測から直接言えること**

1. **上表の 1〜5 は「1 回目だから」以外の理由が無い保留**なので、**廃止と同時に判断可能になる**（判断そのものはこれから行う）。
2. **DR-0070 は 2 段になる。**6 周の逸脱の分類（手8c の検算）は**②③ だけで全件同じ結論に落ちる**——
   Select 幅・cell 書式は「語彙で表せる」、document reset は「責務に割り当てられる」、accessor の ReactNode は「No で残す」。
   🟦 **規則①が単独で結論を決めた行は 1 つも無い**（素材層 15 件は 0 回だが、②③ でも棄却される）。
   → **廃止しても手8c・手8d の実装判断は 1 件も変わらない。**
3. 🟥 **手8f の D1 の理由が 1 本消える。**選択肢 B（打ち手を先に打つ）は**規律違反ではなくなった**ので、
   中身で比べ直す必要がある（→ 手順書 §2.1 を書き直した）。

**🟥 推論（未検証）**

- **1 回で動けるようになると、「ばらつき」に反応して部品を作る危険が出る。**
  🟥 本 repo は r1〜r7 で**同一入力のばらつきを一度も測っていない**ので、
  **1 回の観測が「効果」なのか「揺れ」なのかを区別する手段が無い。**
  → **手8f の Q1（同一入力の再現性）がこの危険の実測にちょうど対応する。**
  **2 回ルールは、床を測らずに済ませるための代用品として働いていた**可能性がある（🟥 未検証）。
- 上表 1〜5 を実際に判断したとき、**何件が「作る」に倒れるかは分からない。**
  🟨 全部が保留のまま残るなら、止めていたのは規律ではなく別のもの（時間・優先度）だったことになる。
