# DR-0097: 例外が全量を覆っていて、規則の形が見えなかった

## 背景

[部品の完成バー](../部品の完成バー.md) §3 は面②（a11y）のバーをこう定義している——

| impact | バー |
| --- | --- |
| **critical** | 🟥 **0**（落とす） |
| **serious** | 🟨 **件数を台帳に載せる**（**落とさない**） |

[DR-0096](DR-0096-overlays-that-no-story-opens-are-invisible-to-every-check.md) で
`aria-dialog-name`（**impact: serious**）が出たとき、**バーは落ちた。**
定義どおりなら**落ちないはず**だった。

## 発見

**実装は impact を 1 度も見ていない。**

`.storybook/preview.tsx` は `a11y: { test: 'error' }` を置き、
**rule 単位で 2 つだけ無効化**している（`color-contrast` と `region`）。
**それ以外は impact に関係なく全部落ちる。**

★★★ **1 年ぶんの記録を見ても、この食い違いに気づいた回が無い。**
理由は数字が示している——

| 時点 | serious の件数 | その内訳 |
| --- | --- | --- |
| 部品1 B1-04 | 77 | 🟥 **77/77 が `color-contrast`**（無効化済み） |
| 部品1 B1-06 | 113 | 🟥 **113/113 が `color-contrast`** |
| 🆕 部品3 C3-09 | 142 | 🟥 **142/142 が `color-contrast`** |

**serious は「1 つの例外」で全量が覆われていた。**
→ **「serious は落とさない」という記述は、一度も検証されないまま正しく見えていた。**
**規則が働く場面が 1 度も来なかったから、規則の形が間違っていることに気づけない。**

★ **これは「対象 0 件で緑」の親戚だが、別物**——
「対象 0 件で緑」は**検査の対象が無い**形、本件は**例外の対象が全部だった**形。
**前者は検査が空振りし、後者は例外が空振りしない（＝ 常に効く）。**

## 根拠（実測・2026-08-09）

- `DatePicker/Open` の `aria-dialog-name`（**serious**）で **`pnpm test-storybook` が exit 1**。
- 出荷物の棚の a11y 再計測（`tools/a11y-scan.mjs`・story 124 題）:
  **critical 0 ／ serious 142 ／ rule は `color-contrast` の 1 種類のみ**。
  → **`color-contrast` を無効化した瞬間、serious は 0 件になる**＝
  **「serious を落とすかどうか」を決める場面が今日まで来なかった。**

## 影響

**観測から直接言えること**

- 🟦 **実装のほうが正しかった。**今回まさに「落ちない側」の記述に従っていたら、
  **`aria-dialog-name` は台帳の数字になって誰も直さなかった**（[DR-0096](DR-0096-overlays-that-no-story-opens-are-invisible-to-every-check.md)）。
  → **定義を実装に合わせて直す**（[部品3 D11=A](../手順/部品3_DatePickerと射程の外の3件.md)）。
  正しい記述は「**serious は落とさない**」ではなく「**`color-contrast` を rule 単位で無効化してある**」。
- **impact で線を引く設計と、rule で線を引く設計は別物**——
  前者は「重さ」で切り、後者は「**この欠陥は部品側で直せない**」で切る。
  🟦 **この repo が実際に採っていたのは後者**で、[OBS-0017](../OBS/OBS-0017_意味色とfillの対比が全滅している.md)
  （① 層の配色の決定・部品では直せない）という理由づけも後者の形をしている。
- ★ **文書が「緩い側」に書かれていると、実装が捕まえた欠陥を「無視してよいもの」として
  正当化する材料になる。**——**今回は実装を信じたので助かったが、逆の判断もできた。**

**🟥 推論（未検証）**

- 他の面にも同型の食い違いがあるかは**数えていない**。
  🟨 面③（状態面）は「台帳」と書いてあり実装が無いので**食い違いようがない**が、
  面①・面④・面⑤ は**定義と実装を突き合わせていない**（→ 次の回の観測項目）。
