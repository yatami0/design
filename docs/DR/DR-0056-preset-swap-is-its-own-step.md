# DR-0056: preset 差し替えは独立した手（手8b）

## 背景

未決 #6「`preset` ごと差し替える軸を手5 に含めるか」は
**手2 → 手2b → 手3 → 手4 → 手5 と 5 回持ち越された**。
[OBS-0006](../OBS/OBS-0006_preset差し替えは何の検証なのか.md) が
「持ち越されたのは**いつやるかが決まらなかったからではなく、何を確かめる手かが定義されていなかったから**」
と整理し、**手5 の結果を待って定義する**形にしてあった。

手5 が完了して材料が出たので、棚卸し（2026-08-01）で決着させる。

## 決定

### 1. 🟦 何を検証する手か

**「値では解けない"形"の衝突を、部品の作りを選び直すことで解けるか」を測る手。**

「形」とは `variant` の定義そのもの——**トークンをいくら差し替えても届かない層**。

### 2. 🟦 置き場は **手8b**（独立した手。手7 の系列には入れない）

ユーザー判断（2026-08-01）。**手7（Claude Design が組んだものを使うか作り直すか）とは混ぜない。**

| | 手7 | **手8b** |
| --- | --- | --- |
| 動かすもの | **Claude Design の出力** | **shadcn の preset** |
| 問い | 生成物を使うか、作り直すか | 部品の作りを選び直して形の衝突が解けるか |
| 依存 | `/design-sync` とプレビュー HTML（[DR-0018](DR-0018-design-sync-takes-preview-html.md)） | shadcn CLI のみ |

🟨 **番号は 手2b の前例に倣った**（手8 の後・手9 の前に挿す）。
本 repo の `step` 語彙は `手[0-9][a-z]?` なので **手10 は使えない**。

## 根拠（実測）

**手5 が終わって、preset を動かす動機の大きさが測れるようになった。**
[OBS-0006](../OBS/OBS-0006_preset差し替えは何の検証なのか.md) §4 は「この結論が変わる条件」を
**「トークンで解けない衝突が多く残った場合」**と定めていた。実測した内訳:

| 手5 で残ったもの | 件数 | **preset を替えたら解けるか** |
| --- | --- | --- |
| 不透明度修飾（[DR-0045](DR-0045-opacity-modifiers-were-invisible-to-lint.md)） | **58 箇所** | 🟥 **解けない。**「意味色 × 不透明度」は shadcn 共通の機構で、preset に依らない |
| variant の取り残し（[DR-0047](DR-0047-cost-of-forcing-the-swap-through.md)） | **7 箇所** | 🟥 **解けない。**レイヤ外上書きが兄弟クラスに届かないという機構の話 |
| 丙・本当に変わらない（[DR-0043](DR-0043-recount-of-fifteen-unchanged-spots.md)） | **1 件** | 🟥 解けない（`--sidebar-width` のモバイル） |
| **形の衝突**（[トークンマッピング 表3](../トークンマッピング.md) #1 塗り CTA・#7 `h-8`） | **2 件** | 🟦 **ここだけが対象** |

🟦 **数が多いほうは preset では解けず、preset で解ける可能性があるのは 2 件だけだった。**
→ **「トークン差し替えの延長」ではない**ことが数字で確定した。別軸である。

🟦 **表3 の #3（blur）・#5（weight 500）は既に脱落している。**
[DR-0041](DR-0041-tailwind-v4-seams-differ-per-utility.md) で**トークン側から解けた**ため、
「preset を変えないと解けない」と思われていたものは実測のたびに減ってきた。

## 影響

**観測から直接言えること**

- 🟦 **未決 #6 は閉じる。**5 回の持ち越しが終わった。
- 🟦 **[OBS-0006](../OBS/OBS-0006_preset差し替えは何の検証なのか.md) は本 DR へ昇格して閉じる。**
- 🟦 **段取りに 手8b が入る。**[UI検証の位置づけと段取り.md](../UI検証の位置づけと段取り.md) §5 の図と表を更新した。
- 🟨 **手8b は「やらない」を選べる手。**対象が 2 件しかないので、
  **手7・手8 の結果次第では「動機が薄いので実施しない」という結論もありうる。**
  それも記録すれば成果になる（[DR-0007](DR-0007-shadcn-output-handling.md) の「赤の内訳が成果物」と同型）。

**🟥 推論（未検証）**

- 🟥 **形の衝突 2 件が本当に preset で解けるかは確かめていない。**
  他の preset（`nova` 以外）が「塗り CTA」や `h-8` をどう定義しているかを**一件も見ていない**。
  → **検証方法**: 手8b で別 preset を 1 つ入れ、`button.tsx` の `cva` を差分で読む。
  🟥 **解けなかった場合、この手の結論は「preset では解けない＝作り直すしかない」になる。**
- 🟥 **手8b が手7 と独立だという判断は、動かす対象が違うことに基づく。**
  実際に走らせたら観測が重なる可能性は残る（どちらも「部品を作り直すか」に効く）。
