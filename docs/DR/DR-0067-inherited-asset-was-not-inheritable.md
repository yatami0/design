# DR-0067: 「引き継ぐ」と書いた資産が引き継げなかった

## 背景

[段取り §7](../UI検証の位置づけと段取り.md) は「前回の検証（`~/git/CC-Skills`）から引き継ぐもの」として
`validate.mjs` / `anti-slop.mjs` を挙げ、「**🟦 design repo でも効かせる（lint と二重の網）→ 手8**」と書いていた。
手8 の Q4 はこの行の検算にあたる。

## 発見

### 1. 🟥 この機械に `~/git/CC-Skills` が無い

環境が **WSL2 → macOS ＋ Conductor の worktree** に変わっており、ローカルの clone が存在しない。

### 2. 🟥 GitHub のリポジトリは空だった

```
$ gh repo clone yatami0/CC-Skills
$ git log --oneline   → d620737 Initial commit
$ ls                  → README.md のみ（本文は "# sdd"）
```

`web-design-mock` も `distill` も `_philosophies/aux-admin` も `validate.mjs` / `anti-slop.mjs` も、
**一度も push されていない。**public リポジトリとして存在はするが、中身は初期コミットのみ。

### 3. 何が残り、何が失われたか

| | 内容 |
| --- | --- |
| 🟦 **失われていない** | `tmp-admin` のトークン**値**。手5 で `src/app/tmp-admin.css` として本 repo へ移送済み |
| 🟥 **失われた** | `validate.mjs` / `anti-slop.mjs` の**実装**。本 repo に写した形跡が無い |

🟥 **本 repo が記録していたのは「依存ゼロの Node スクリプト」「🟦 流用できる」という判定だけ**で、
**中身も、何を検査するかの一覧も、一行も写していない。**

## 根拠（実測）

2026-08-02。`gh repo list yatami0` で public リポジトリとして存在することを確認したうえで clone。
`git log` が 1 コミット、作業ツリーに `README.md` のみ。ブランチは `main` だけ。

本 repo 側の記録は `grep -rn "validate\.mjs\|anti-slop" docs/` で全件確認した——
段取り §6・§7 とハンドオフ・手順書の言及だけで、**実装への参照も引用も無い。**

## 影響

**観測から直接言えること**

1. ★ **段取り §7 の「🟦 design repo でも効かせる（lint と二重の網）→ 手8」は実行不能。**
   手8 の Q4 の答えは「**射程が違った**」でも「**補わなかった**」でもなく「**測れない**」。
2. ★ **「流用できる」は所在の確認であって、可用性の確認ではなかった。**
   [DR-0005](DR-0005-token-ownership-and-two-stage.md) は `tmp-admin` について
   「`status: approved`・D4 汎化検証済み」まで確かめて引き継ぎ、**実際に値を写した**ので生き残った。
   `validate.mjs` は**判定だけして写さなかった**ので失われた。**同じ文書の中で扱いが割れていた。**
3. 🟥 **本 repo の「一次情報を実測で置き換える」規律が、外部資産には適用されていなかった。**
   公式ドキュメント（DR-0006）や自分の DR（DR-0029）は実測で覆してきたが、
   **「隣のリポジトリにあるはず」は 1 度も実測していない。**

**🟥 推論（未検証）**

- **ユーザーの旧環境（WSL2 側）には実物が残っている可能性がある。**
  発掘すれば Q4 は測れる。🟥 **本 DR は「この機械から取得できない」ことしか言っていない。**
- **仮に手に入っても射程が合うかは別問題。**CC-Skills は**単一ファイル HTML 出力が前提**（段取り §6）で、
  🟨 `.dc.html` も単一ファイル HTML なので**合う可能性はある**が、読まないと分からない。
