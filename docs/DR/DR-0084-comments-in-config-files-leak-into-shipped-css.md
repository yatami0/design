# DR-0084: 設定ファイルのコメントに書いたクラス名が配布 CSS に湧く — 禁止の説明文が禁止対象を生成する

## 背景

工程1 P1-05 で CSS を `src/styles/` へ移設した後、`@source not '../../docs'`（DR-0021）が
効き続けているかを正負の対照で確かめたところ、負の対照に選んだ `text-gray-600` が生成 CSS に**在った**。

## 発見

- 生成 CSS（storybook build の出力）に **`.text-gray-600` と `.p-13` が存在する**。
  どちらも **`src/` の使用箇所は 0 件**——出どころは **`eslint.config.mjs` のコメントと message 文字列**
  （「`text-gray-600` は Tailwind のパレット 288 色の 1 つ」「`p-13` は正当な Tailwind クラス」）。
- **禁止規則を説明するために書いた完全形のクラス名が、Tailwind v4 の走査に拾われて
  配布 CSS にユーティリティとして生成されている**。lint はこのクラスの使用を止めるが、
  CSS には存在する——「書けないが、在る」状態。
- 一方 **docs にだけある `p-7`（15 箇所）は生成 CSS に無い**——`@source not '../../docs'` は
  `src/styles/` への移設後も効いている（正の対照 `w-field-md` も生成されている）。

## 根拠（実測）

- `grep -c "\.p-13{" storybook-static/assets/*.css` → 1／`grep -rlw "p-13" src …` → `eslint.config.mjs` のみ
- `grep -c "\.text-gray-600" …` → 1／`src` 内の使用 0 件
- `grep -c "\.p-7{" …` → 0（docs 13 ファイルに実在・docs 以外 0 件）
- 2026-08-07・tailwindcss 4.3.3（@tailwindcss/vite）。工程1 以前（@tailwindcss/postcss）から
  同条件のはず——**気づいたのが今日というだけで、新規発生ではない可能性が高い**（旧 CSS では未測定）

## 影響

**観測から直接言えること**

- 配布 CSS には**リポジトリのどのコードも使っていないクラスが混入している**。出荷 CSS の純度を
  規約にするなら、走査範囲（`@source`）の設計に**設定ファイル**を含めて考える必要がある。
- 「docs は走査から外した」（DR-0021）の対処は**ファイル種の問題ではなく走査範囲の問題**——
  同じ形の穴が `.mjs` にも開いていた。

**🟥 推論（未検証）**

- `@source not` を `eslint.config.mjs` にも張れば消えるはず。ただし**サイズ実害は数十 byte**なので、
  対処するかどうか自体が未決（消すなら「純度」の理由で消す。サイズの理由では動かない）。
