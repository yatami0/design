# DR-0073: 使用制限を焼いたのは取得情報の量ではなくコンテキストの再読

## 背景

2026-08-07 の午前（JST 08:59〜11:04、手8c の設計作業）で使用制限に到達した。
体感では「調査をたくさんしたから」だったが、**8/2 にも同じ壁に当たっている**
（8/2 の subagent 2 本が `You've hit your session limit · resets 10:10pm (Asia/Tokyo)` で落ちている）。
2 回目なので原因を実測で確定させる。

## 発見

### 1. 🟦 入力トークンの 83% は本体セッションのコンテキスト再読

対象セッション `d65aa0d8-f01d-4fd0-b859-b7aef423667f`（UTC 2026-08-06T23:00 以降）。

| | API 呼び出し | cache_read | cache_create | output |
| --- | ---: | ---: | ---: | ---: |
| 本体セッション | 177 | **47,703,535** | 1,467,814 | 355,172 |
| subagent 5 本 | 280 | 9,004,010 | 786,827 | 101,392 |
| **合計** | **457** | **56,707,545** | 2,254,641 | 456,564 |

本体の入力合計 49,171,349 ÷ 177 回 = **1 往復あたり平均 277,804 トークン**。

### 2. 🟦 効いたのは往復回数であって、取ってきた情報の量ではない

同区間で本体セッションが受け取った**ツール実行結果は全部合わせて 36,586 文字**（約 1 万トークン）。
一方ツール呼び出しは **97 回**（Edit 54 / Bash 25 / TaskUpdate 7 / Write 6 / Agent 5）。

**1 回ごとに 190k〜353k を丸ごと読み直している。**
つまり `情報量 ≒ 1 万トークン` に対し `再読 ≒ 4,770 万トークン`。**比で 4,700 倍。**

### 3. 🟦 コンテキストは一度も圧縮されず単調増加した

| 時刻（UTC） | コンテキスト |
| --- | ---: |
| 2026-08-06 23:59（再開直後） | **190,552** |
| 2026-08-07 00:15 | 273,566 |
| 2026-08-07 00:24 | 334,148 |
| 2026-08-07 01:06 | 352,660 |

- **開始時点で既に 190k。**「続き再開して」で 8/2 のセッションをそのまま再開したため
- セッション全体の初回呼び出しは 28,458（system prompt + tool 定義 + CLAUDE.md / PARADIGM.md）。
  つまり**新規セッションなら 28k から始められた**
- モデルは `claude-fable-5`（長コンテキスト）。**190k → 353k の間で auto-compact が一度も発火していない**

### 4. 🟦 subagent のレポートは通知に全文が乗り、本体の文脈に永久に残る

`<task-notification>` は `<result>` 要素にレポート本文をそのまま含む。
10 件の通知で**累計 82,344 文字**（Ark UI 17,266 / Radix 14,675 / Polaris 13,296 / 宣言的な列 API 12,033 …）。

**`TaskOutput` の呼び出しは 0 回。`<output-file>` を Read した回数も 0 回。**
要約して取り込む経路は一度も通っていない。

### 5. 🟦 subagent 消費の 52% は本体に届かないまま捨てられた

| agent | 内容 | cache_read | output | 通知 |
| --- | --- | ---: | ---: | --- |
| a9e4e2ff | React Aria と Spectrum | **3,757,685** | 28,305 | ❌ 無し |
| a058782b | document reset の届け方 | **1,359,303** | 20,015 | ❌ 無し |
| afa591dd | Ark UI と Chakra | 1,992,864 | 23,666 | ✅ |
| a3c0298c | Polaris | 969,587 | 14,878 | ✅ |
| a829ee67 | 宣言的な列 API | 924,571 | 14,528 | ✅ |

上 2 本は **jsonl の末尾に最終レポート本文が残っている**（＝仕事は完走した）が、
本体セッション側に `task-notification` の記録が無い。**5,116,988 トークンぶんが不着。**

同じことが 8/2 にも起きている（shadcn `a0ed5079` と Primer `ac59ea3f` は通知が無い）。
8/2 に投げた 8 本のうち**本体に届いたのは 3 本**（Radix / Base UI・MUI / Carbon）。

### 6. 🟦 今日の subagent 5 本のうち 3 本は 8/2 の作り直し

React Aria / Ark UI / Polaris は 8/2 に投げて失敗したものの再実行。
React Aria に至っては**プロンプトが 1,681 文字で完全一致**している。

## 根拠（実測）

`~/.claude/projects/-Users-takumi-conductor-workspaces-design-amman/` の
セッション jsonl と `subagents/agent-*.jsonl` を `jq` で集計した（2026-08-07 実施）。

- トークン: `.message.usage` の `cache_creation_input_tokens` / `cache_read_input_tokens` / `output_tokens` を
  `.timestamp >= "2026-08-06T23"` で絞って合算
- ツール呼び出し: `.message.content[] | select(.type=="tool_use") | .name` を集計
- ツール結果の文字数: `.message.content[] | select(.type=="tool_result") | .content|tostring|length` を合算
- 通知: `.message.content|tostring|test("task-notification")` に一致する user メッセージを全件列挙
- **同区間で他のワークスペースは動いていない。**`~/.claude/projects/` 配下の全 jsonl を
  同じ条件で走査し、消費元がこのセッションと subagent だけであることを確認した
- 設定: `~/.claude/settings.json` に compact 関係の指定は無い（既定）

## 影響

**観測から直接言えること**

1. ★ **長い調査セッションのコストは「何を取ってきたか」では説明できない。**
   支配するのは `往復回数 × その時点の文脈量`。今回は情報量 1 万トークンに対して再読 4,770 万トークン。
2. ★ **セッションを跨いで再開すると、初期コストが 28k → 190k（6.8 倍）になる。**
   この repo は `docs/handoff.md` が状態の正本なので、**再開経路として「続き再開して」は不要**だった。
3. ★ **長コンテキストのモデルでは auto-compact が救ってくれない。**
   353k まで伸びても発火しなかった。**短いモデルなら途中で切れていた**という意味で、
   コンテキスト長は「余裕」ではなく「請求書」として効く。
4. ★ **subagent は投げた分が届くとは限らない。**8/7 は 5 本中 2 本、8/2 は 8 本中 5 本が不着。
   **不着でも消費は発生している**（8/7 だけで 5.1M）。
5. ★ **同じ壁に 2 回当たっている**（8/2・8/7）。2 回ルールの成立要件を満たす。

**🟥 推論（未検証）**

- 🟥 **不着の原因は特定していない。**「セッションが通知前に閉じた」「通知が落ちた」の
  どちらかは jsonl からは判別できない。**次に subagent を投げたら、完了後に
  `TaskOutput` を明示的に呼んで届いたかを確かめれば切り分けられる。**
- 🟥 **output 355,172 に対し、本体に保存された assistant の可視テキストは約 130,000 文字。**
  差分の多くは thinking と推測されるが、jsonl は thinking を全量保存しないので**確認できていない**。
- 🟥 **「Edit を 54 回に刻んだこと」がどれだけ効いたかは分離できていない。**
  往復数の 56% を占めるので効いたはずだが、まとめて Write した場合との対照は取っていない。
