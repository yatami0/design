# DR-0034: 見た目 32px ／ 当たり判定 44px（手3 D7）

## 背景

[DR-0023](DR-0023-real-conflict-is-touch-target.md) は「tmp-admin の 44px（不可侵の下限）と nova の `h-8`(32px) が
正面からぶつかる」とし、**哲学とプリセットのどちらを優先するかの二択**として手3 に送った。
[DR-0030](DR-0030-touch-target-provenance-corrected.md) で出どころを辿った結果、**前提が崩れて選択肢が 7 つに開いた。**

## 決定

**B ＋ D ＋ F の合成を採る。**（ユーザー判断 2026-07-26）

| 要素 | 決め |
|---|---|
| **見た目** | 🟦 **nova の 32px を採る**（B）。管理画面の高密度を維持する |
| **当たり判定** | 🟦 **製品層のラッパーで 44px に拡張**（D）。`position: relative` ＋ `::after { inset: -6px }` |
| **適用条件** | 🟦 **`@media (pointer: coarse)` で限定**（F）。タッチ環境でだけ効かせる |
| **nav-item** | 🟦 **`min-height: 44px` を見た目でも守る**。tmp-admin が名指しで規定している唯一の箇所 |
| **素材層** | 🟥 **1 行も触らない**（すべて製品層のラッパー側で実装する） |

### 思想への提案（書き換えない）

`apple.md` §4.5 の「タッチターゲット **44×44px 以上**」を **当たり判定に対する要求**と読めば、
**見た目 32px と両立する。**同ファイルは適用範囲を書いていないので、**範囲は本 repo が決めてよい**と解釈する。

## 根拠（実測）

2026-07-26。詳細は [タッチターゲットとサイズ密度.md](../タッチターゲットとサイズ密度.md)。

1. **tmp-admin は 44px を `nav-item` の `min-height` 1 箇所にしか適用していない**（`aux-admin.md` §4.2）。
   「全コントロールの下限」と読んだのは本 repo の誤読だった。
2. **WCAG の適合ラインは 24×24px（SC 2.5.8 / Level AA）**で、nova の 32px は満たしている。44×44 は SC 2.5.5 / **AAA**。
3. **Apple 自身が「タップできる面積であって見た目ではない」と定義している**＝ 見た目と当たり判定は分離してよい。
4. **検証対象は Redmine の管理画面＝マウス主体**（[DR-0002](DR-0002-verify-three-layers-not-screens.md)）なので、
   `pointer: coarse` の分岐は実コストがほぼゼロ。
5. tmp-admin §4.4 は**テーブル行高 60px** を規定しており、行内のコントロールは元々間隔に余裕がある。

### 捨てた案と理由

| 案 | 捨てた理由 |
|---|---|
| **A** 見た目ごと 44px | nova の高密度が壊れる。**そもそも哲学がそこまで要求していない**（根拠 1） |
| **C** 用途で使い分け | 場面ごとの判断が要り、機械化できない。D なら一律に効く |
| **G** 高さを semantic token 化 | 🟨 **却下ではなく先送り。**`h-8` は CSS 変数ではないので前段の置き換えが要る。必要性はまだ 1 度も証明されていない（2 回ルール） |

## 影響

- 🟥 **検証手段に穴がある。**`addon-a11y` の axe-core **4.12.1** が持つ `target-size` ルールは
  タグが **`wcag22aa` / `wcag258`＝ 24px の AA**（実測）。**44px は測らない。**
  → **44px の達成は目視 + DevTools で測る**と手順書に書く。「a11y が緑だから 44px を満たしている」は成り立たない。
  → 手2b D10 が `addon-a11y` を残した根拠のうち「44px を機械で測れる」は**成り立たない**（残した判断自体は妥当）。
- 🟦 **未決 #11 が閉じた。**思想の対立ではなく実装選択だったので、**どちらも捨てずに済んだ。**
- 🟨 **[トークンマッピング §5](../トークンマッピング.md) の「部品を触らないと解けない 7 件」から touch-min が外れる。**
  手5 の事前特定 15 件を数え直す（未決 #18）。
