# DR-0101: 「無いことを落とす検査」がコメントで通っていた

## 背景

[DR-0099](DR-0099-the-blind-spot-list-must-be-machine-derived.md)（部品4 D4=C）で、
**射程の外の一覧を機械が引く 2 段の検査**を置いた。

| 段 | 何を言うか | 実装 |
| --- | --- | --- |
| **静的** | **主張を持つ story が在るか** | `tools/opened-overlay-check.mjs`（素材層の `Primitive.Portal` から引く） |
| **動的** | **その主張が真か** | `src/stories/opened.ts` の `expectOpened(slot)` |

🟨 **部品4 の手順書 C4-04「詰まったら」欄は、この形の危うさを名指ししていた**——
「**静的側の走査が『grep が当たるかどうか』に落ちると脆い**」。
🟥 **1 回で現実になった。**

## 発見

[部品5](../手順/部品5_判定の保留と描かれていない状態.md) C5-05 で `Sidebar/Mobile` の story を書き、
**説明文（JSDoc）に `expectOpened('sheet-content')` という文字列をそのまま引用した。**

**その瞬間、検査の出力が変わった:**

```
🟦 sheet-content   sheet.tsx   src/stories/Navigation/Sidebar.stories.tsx   ← Sheet.stories.tsx ではない
```

**静的側の正体は 1 本の正規表現だった:**

```js
for (const m of src.matchAll(/expectOpened\(\s*'([a-z-]+)'\s*\)/g)) { … }
```

🟥 **コメントも文字列リテラルも区別していない。**

### 赤テストで確かめた（2026-08-09）

| 検体 | 結果 |
| --- | --- |
| `Sheet.stories.tsx` の**本物の主張**を消す（コメントは残す） | 🟥 **検査は緑のまま**（`exit 0`） |
| **コメントを落としてから走査する**ように直して、同じことをする | 🟦 **赤**（`exit 1`・`sheet-content` が「開いた story が無い」） |
| 主張を戻す | 🟦 **緑**（担当も `Sheet.stories.tsx` に戻った） |

★★★ **「無いこと」を落とすために作った検査が、"書けば通る" 形だった。**
**しかも書くのはコードでなくてよく、説明文で足りた。**

## 影響

### 🟦 観測

- 🟦 **塞いだ**（部品5 D11=A）——**`/* */` と `//` を落としてから走査する**。
  🟨 **限界**: 文字列リテラルの中の `//` も落ちる。**ただし落ちる方向は「主張が減る」側だけ**なので、**偽の緑は作らない**
- 🟥 **この穴は 2026-08-09 に置かれ、同じ日に見つかった**——**間に挟まったのは 1 回の PR**（部品4）

### 🟥 推論（まだ確かめていない）

- **同じ形の grep を持つ検査が他にもある**：`tools/title-map-check.mjs` ／ `tools/dead-class-scan.mjs` ／
  eslint の `no-restricted-syntax`（**こちらは AST なのでコメントを見ない**）。**数えていない**
- **「主張が本当に `play` の中で実行されるか」は、静的側では依然として言えない**——
  `const s = 'sheet-content'` のように**変数へ逃がせば検体は消える**（`opened.ts` の JSDoc が
  「変数に逃がさない」と書いているのは、**機械ではなく人への依頼のまま**）

## 一般則（この repo に効く形）

> **ソースを文字列で検査するものは、コメントを先に落とす。**
> **落とさないと、「検査を通すために書く 1 行」が、"検査対象の実装" と同じ重さを持ってしまう。**

★★ **これは「型は通るが作用しない」（[DR-0090](DR-0090-token-classes-were-silently-dropped-by-tailwind-merge.md) の `width` ／
部品2 の `Slider` の `aria-label`）の親戚だが、向きが逆**——
**あちらは「書いたのに効かない」、こちらは「書いていないのに効いたことになる」。**
